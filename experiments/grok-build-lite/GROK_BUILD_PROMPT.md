# Grok Build 実験: KP野帳 Lite

## 目的
既存の本番KP野帳を変更せず、Grokの「アプリとサイトをビルド」で現場用Webアプリの最小構成が成立するか検証する。

参照:
- 公開リポジトリ: https://github.com/kanna19840131/kp-yacho
- 現行アプリ: https://kanna19840131.github.io/kp-yacho/

## Grok Build に渡すプロンプト

舗装・道路維持の現場でAndroidスマートフォンから使う「KP野帳 Lite」というモバイルファーストWebアプリを作ってください。

これはデモサイトではなく、実際の現場投入可否を検証するβ版です。見た目より、誤操作しにくさ・保存の確実性・GPS異常時に誤った値を出さないことを優先してください。

既存の本番アプリは以下です。
https://kanna19840131.github.io/kp-yacho/
公開コードは以下です。
https://github.com/kanna19840131/kp-yacho

可能なら既存コードを参照して、R230/R453の路線データおよびGPS→KP算出ロジックを再利用してください。ただし本番リポジトリや本番データは変更しないでください。

### 今回実装する機能
1. GPS開始 / GPS停止
2. 路線モード: 自動 / R230固定 / R453固定
3. 現在KP表示
4. GPSが使えない場合の手動KP入力
5. 左右: R / L / 中央 / -
6. 形状別面積計算
   - 長方形 W×L
   - 台形 W×(L1+L2)÷2
   - 三角形 W×L÷2
   - 面積直接入力
7. 推定係数 ㎡/t を使った推定合材量
8. 合材搬入量・残量入力
9. 施工記録の追加・編集・削除
10. 午前 / 午後 / 合計面積の本日サマリー
11. 端末内保存
12. 全データ削除前の確認ダイアログ

### 今回入れない機能
- 電子黒板
- カメラ
- 天気
- 交通量
- コンビニ検索
- AI機能
- ログイン
- クラウドDB
- 有料機能

### 保存
本番の localStorage キー `kp_yacho_v12` は絶対に読み書きしないでください。
この実験版は `kp_yacho_grok_lite_v1` を使用してください。
ページ再読み込み・ブラウザ再起動後も記録が復元されること。

### GPS安全要件
- `navigator.geolocation.watchPosition()` を使う。
- `enableHighAccuracy: true`。
- GPS未許可、タイムアウト、位置精度不良、路線データ不足、路線判定不能では推測したKPを表示しない。
- 判定不能時は明確に「KP判定不可」と表示し、手動KP入力へ誘導する。
- 路線データがない場合に架空のKPやサンプルKPを生成しない。
- 最後に正常取得したKPを、現在値であるかのように無期限表示し続けない。
- GPS取得時刻と精度(m)を画面に表示する。
- 自動路線判定が曖昧な場合は勝手に決定せず、固定モードか手動入力を促す。

### 入力安全要件
- 0以下の幅・長さ・面積は登録不可。
- NaN、Infinity、空欄のまま面積登録不可。
- 面積は小数第2位表示。
- 合材推定は計算値であり、最終判断ではないことを表示する。
- 編集中であることを画面上で明確にする。
- 削除は確認を入れる。

### UI
- Android Chrome、縦画面、屋外使用前提。
- ダークモード。
- タップ領域を大きくする。
- 重要な現在KP、面積、合計を大きく表示。
- 操作順は「KP確定 → 面積入力 → 記録」の流れが一目で分かること。
- 片手操作を意識する。
- PC向けの横長ダッシュボードにしない。

### 技術方針
- 可能な限りクライアントサイドだけで動作。
- 第三者APIなしでも主要機能が成立すること。
- HTTPS環境で位置情報を利用。
- 外部サービス障害で記録・面積計算まで使えなくならないこと。
- コードはGitHubへエクスポート可能な状態にする。

### 完了条件
アプリ完成後、次を自分で確認して結果を報告してください。
1. 手動KPで記録追加できる。
2. 長方形1×10mが10.00㎡になる。
3. 台形 W=2, L1=3, L2=5 が8.00㎡になる。
4. 三角形 W=2, L=5 が5.00㎡になる。
5. 再読み込みしても記録が残る。
6. 記録の編集・削除ができる。
7. 午前午後の集計が正しい。
8. GPS拒否時に架空KPを表示しない。
9. 路線データを取得・再利用できなかった場合は、その事実を明示し、GPS→KPを完成したと主張しない。
10. `kp_yacho_v12` を一切変更していない。

最初から機能を増やさず、このLite版を完成させてください。実装できなかった項目は、できたふりをせず明示してください。
