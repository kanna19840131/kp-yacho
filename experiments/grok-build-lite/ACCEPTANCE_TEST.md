# KP野帳 Lite 受け入れテスト

## 判定原則
- 見た目より現場で壊れないことを優先する。
- GPSや路線判定に自信がない場合は、推測値を出さず「判定不可」にする。
- 本番 `localStorage['kp_yacho_v12']` を読み書きしない。
- β版の保存キーは `kp_yacho_grok_lite_v1` を使用する。
- Android Chrome 実機で確認する。

## 必須テスト

### 1. 起動
- 初回起動でエラー画面にならない。
- 画面幅がスマホに収まり、横スクロールが不要。
- 主要ボタンが片手で押せる大きさになっている。

### 2. GPS
- GPS開始で位置情報許可を求める。
- 許可後、現在地を取得できる。
- GPS停止で監視が停止する。
- 位置情報を拒否した場合、架空のKPを表示しない。
- GPSタイムアウト時、架空のKPを表示しない。
- 路線データ未取得・判定不能時は「KP判定不可」等の明示状態にする。

### 3. 路線モード
- 自動 / R230固定 / R453固定を切り替えられる。
- 固定モードでは指定外路線へ勝手に切り替わらない。
- 自動判定に自信がない場合は誤判定より警告を優先する。

### 4. 手動KP
- GPS不使用でも手動KPを入力できる。
- R / L / 中央 / - を選択できる。
- 確定したKPが施工記録へ正しく反映される。

### 5. 面積計算
以下を入力して期待値と一致すること。
- 長方形: W=2.0, L=3.0 → 6.00㎡
- 台形: W=2.0, L1=3.0, L2=5.0 → 8.00㎡
- 三角形: W=2.0, L=3.0 → 3.00㎡
- 直接入力: 12.34 → 12.34㎡
- 未入力・不正入力で NaN や Infinity を表示しない。

### 6. 合材推定
- 面積45㎡、係数45㎡/t → 1.00t。
- 係数0・未入力では0除算せず、判定不能を表示する。
- 搬入量・残量を入力しても負数やNaNが表示されない。

### 7. 施工記録
- 行追加できる。
- 午前 / 午後を保持できる。
- 編集して保存できる。
- 削除前に意図しない操作を防げる。
- 複数行追加しても順番と値が壊れない。

### 8. 本日サマリー
例:
- 午前 10㎡ + 20㎡ = 30㎡
- 午後 15㎡ = 15㎡
- 合計 = 45㎡
となること。

### 9. 保存・再読込
- 記録を3件作成する。
- ブラウザを閉じる。
- 再度開いて3件すべて復元される。
- 編集後に再読込して編集内容が残る。
- 本番 `kp_yacho_v12` が変更されていないことを確認する。

### 10. 全データ削除
- 1タップで即削除されない。
- 確認後のみ削除される。
- キャンセル時はデータが残る。

## 現場投入前の即不合格条件
以下の1つでも起きたら本番投入しない。
- GPS失敗時にもっともらしいKPを勝手に表示する。
- R230/R453を誤判定しても警告が出ない。
- 保存した記録が再読込で消える。
- 面積計算が現行仕様と違う。
- 本番保存キー `kp_yacho_v12` を上書きする。
- Android Chromeで主要操作ができない。
- 入力途中の誤タップで全データが消える。

## 合格ライン
- 必須10項目を全通過。
- 即不合格条件が0件。
- その後、現行KP野帳との並行運用で実現場3回以上確認してから本番統合を検討する。
