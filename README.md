# KP野帳

舗装・道路維持の現場で発生する「KP確認」「施工記録」「面積計算」「黒板作成」「写真撮影」の手間を減らすために開発している現場支援Webアプリです。

## 開発者表記

**企画・設計・開発：石川義晴**  
**AI開発支援：ChatGPT**

本プロジェクトの発想、現場要件、画面構成、運用設計、試験、修正判断は、舗装現場の実務経験をもとに石川義晴が行っています。コード実装の一部には生成AIを利用しています。

## 開発方針

- 現場で実際に発生している手間を削減する
- 一度入力した情報を可能な範囲で再利用する
- 現場責任者がスマートフォンだけで扱えるようにする
- 最終判断は人が行う

## 現在の主な機能

- KP野帳
- 面積・数量管理
- 電子黒板β
- 電子黒板付きカメラβ

## 担当路線専用 KP野帳 β

有料βの商品化検証用として、現行 `index.html` を壊さずに外販向けの軽量版を分離しています。

- `beta.html`: 担当路線専用のβ画面。推定KP、手動KP、施工前登録、面積、写真確認、合材、当日集計、端末内保存、過去日アーカイブ、JSONバックアップに限定。
- `beta-app-core.js`: β版の保存・連番・面積・バックアップ等の純粋ロジック。
- `beta-route-package-builder.html`: KMLと既知KP JSONから顧客別の路線パッケージを端末内で作成する販売者用工具。
- `beta-route-package.example.json`: 架空座標だけを使った路線パッケージ例。
- `BETA_ROUTE_SETUP.md`: 顧客路線の設定手順。
- `BETA_RELEASE_CHECKLIST.md`: 有料納品前のP0チェック。

このリポジトリは公開です。顧客から受領した非公開KML、契約図書、現場固有座標などをcommitしないでください。顧客別データは路線パッケージJSONとして個別に扱います。

β版のGPS表示は現場確認用の**推定KP**です。登録路線から離れすぎた場合、またはKPアンカー範囲外では自動KPを採用しません。測量・行政提出値・出来形の確定用途を保証しません。

## 注意

電子黒板付きカメラβは、正式な改ざん検知機能を備えた電子小黒板対応製品ではありません。現時点では試験運用・社内確認用途を想定しています。
