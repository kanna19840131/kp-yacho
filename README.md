# KP野帳

舗装・道路維持の現場で発生する「KP確認」「施工記録」「面積計算」「黒板作成」「写真撮影」の手間を減らすために開発している現場支援Webアプリです。

## 開発者表記

**企画・設計・開発：石川義晴**  
**AI開発支援：ChatGPT**

本プロジェクトの発想、現場要件、画面構成、運用設計、試験、修正判断は、舗装現場の実務経験をもとに石川義晴が行っています。コード実装の一部には生成AIを利用しています。

## 開発方針

- 現場で実際に発生している手間を削減する
- 一度入力した情報を可能な範囲で再利用する
- 現場責任者がスマートフォンだけで扱えるようにする
- 最終判断は人が行う

## 現在の主な機能

- KP野帳
- 面積・数量管理
- 電子黒板β
- 電子黒板付きカメラβ

## 注意

電子黒板付きカメラβは、正式な改ざん検知機能を備えた電子小黒板対応製品ではありません。現時点では試験運用・社内確認用途を想定しています。
